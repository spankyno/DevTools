Otras utilidades:

* HTTP Status Codes: catálogo de códigos HTTP y explicaciones.

* URL Parser: separar protocolo, dominio, puerto, ruta, parámetros y fragmentos.

* Query String Builder: construir parámetros URL.

* IP Address Info: analizar direcciones IPv4 e IPv6.

* CIDR Calculator: calcular redes, máscaras, rangos y subredes.

* IPv4/IPv6 Converter: conversiones y representaciones.

* User-Agent Parser: identificar navegador, sistema operativo y dispositivo.

* MIME Type Lookup: consultar tipos MIME y extensiones.

* Port Reference: catálogo de puertos y servicios habituales.

* DNS Record Reference: consultar los tipos A, AAAA, CNAME, MX, TXT, NS y SRV.

Nota técnica: las consultas reales a APIs, DNS o direcciones externas pueden estar limitadas por CORS. Algunas necesitarán un pequeño backend o Cloudflare Worker.

### 13\. Funcionalidades especiales que añadiría

Estas pequeñas características pueden hacer que la aplicación destaque frente a otras cajas de herramientas para desarrolladores.

* Multi-tool: ejecutar varias conversiones simultáneamente.

* Quick Search: buscador global que encuentre herramientas escribiendo palabras clave.

* Clipboard Tools: detectar y transformar automáticamente contenido del portapapeles, siempre con permiso del usuario.

* Batch Processing: procesar múltiples archivos de una sola vez.

* Favorites: guardar herramientas favoritas.

* History: recuperar las últimas operaciones realizadas.

* Code Snippets: guardar fragmentos de código reutilizables.

* Workspace: guardar configuraciones y proyectos localmente.

* Dark/Light Mode: dos temas visuales.

* Keyboard Shortcuts: atajos de teclado para las operaciones frecuentes.

* Export: descargar resultados en TXT, JSON, CSV o archivos compatibles.

* Offline Mode: funcionamiento sin conexión mediante PWA.
